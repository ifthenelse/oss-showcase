OSS Showcase

Your code runs. Show people how. OSS Showcase is an Agent Skill for building a README, real demo, and GitHub Pages site from a working repo.

Install OSS Showcase

From your project folder, run this command with Node.js and npm installed. Choose your agent when prompted.

npx skills add ifthenelse/oss-showcase --skill oss-showcase

Run $oss-showcase in Codex or /oss-showcase in Claude Code. In GitHub Copilot, ask it to use OSS Showcase in the current project. It starts with an ordered plan.

What is OSS Showcase?

OSS Showcase is an Agent Skill for maintainers preparing a GitHub project launch. It uses repository files, examples, and tests to plan a README, reproducible demo, static Pages site, and channel drafts.

What happens before the first edit?

OSS Showcase proposes an ordered plan and asks how you want to proceed. Approve one step, approve the remaining eligible local steps, or skip the current step. The handoff records unfinished work. Public publishing requires a separate confirmation.

What does the Task Counter demo show?

A small Python CLI counts task names. The 58-second recording shows Codex CLI, Claude Code CLI, and Claude Desktop planning a showcase for that fixture and stopping at the first decision.

Which files reach GitHub Pages?

A Python generator builds static HTML, CSS, and a sitemap. The validator stages the files listed in the public manifest and rejects content that differs from the reviewed hashes. The handoff and private notes stay outside the Pages artifact.
