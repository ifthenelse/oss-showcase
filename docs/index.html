OSS Showcase

An Agent Skill for maintainers. Build an evidence-backed README, record a reproducible demo, and generate and validate a static GitHub Pages site.

Install and run

From the folder you want to showcase, install the skill with Node.js and npm available. Choose your agent when prompted.

npx skills add ifthenelse/oss-showcase --skill oss-showcase

Open a session in the target project. Run $oss-showcase in Codex or /oss-showcase in Claude Code. The current default branch starts by proposing a plan.

See the skill in action

What does OSS Showcase produce?

It helps you prepare a README, a reproducible demo, a static project page, and launch drafts. Public claims and examples come from project files or tests. The static generator stages a reviewed file list before GitHub Pages deployment.

What stays under your control?

Approve one step at a time or authorize the remaining eligible steps in the plan. Public destinations and payloads need explicit approval. The skill records unfinished work in docs/HANDOFF.md in the target project.

Can I review an existing project first?

Yes. Use the audit mode for a read-only review of the existing showcase. Use launch mode to prepare channel drafts and publish mode to execute an approved publication.
