# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-25

## Context

Decisions about the skill workflow, artifact contracts and publishing boundaries need a durable record alongside the implementation.

## Decision

Record each material architecture decision in a sequentially numbered ADR in this directory. Use the [ADR template](0000-template.md) and review the record alongside the change it describes. Supersede an accepted decision with a new ADR that links to the original.

## Alternatives considered

A separate wiki requires reviewers to reconcile its history with the code. Pull request discussions provide context but are harder to discover from the checkout.

## Consequences

Architecture rationale is available in the repository. Routine edits use the normal pull request description.
