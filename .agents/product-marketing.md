# OSS Showcase positioning

For maintainers who already have a working GitHub repo and want a stranger to be able to install it, see it run, and find the project page. OSS Showcase is an Agent Skill that starts with a reviewable plan and keeps the README, real demo, and Pages site tied to the same project evidence.

Lead with a concrete hook: “Your code runs. Show people how.” Use the Task Counter recording to show the pause before the first edit, then point to the deterministic generator and staged public files. Use short sentences. One emoji can cue the demo in a social post. Avoid invented testimonials, license claims, time saved, release promises, and unsupported compatibility claims.

See the [market discovery memo](showcase/research.md) for alternatives, evidence and search intents.
