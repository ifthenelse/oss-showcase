# Rizz Goblin Panic Button

A fictional Python CLI that turns desk chaos into a goblin alert. Built as a local test project for OSS Showcase.

Requires Python 3.10 or later. No third-party dependencies.

```sh
python3 rizz_goblin.py cursed-tabs keyboard-crumbs
```

Expected output:

```text
Goblin alert: TOUCH GRASS (5 chaos points)
```

Run the tests:

```sh
python3 -m unittest
```
