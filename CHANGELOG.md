## 0.1.0 (2026-11-25)

Initial release of OSS Showcase, an Agent Skill for preparing a project's public presentation from repository evidence.

- Build or refresh a README and static project site from shared facts. Validate the files staged for GitHub Pages.
- Review an existing showcase in audit mode, or prepare release and launch materials for review.
- Use `publish` for an approved GitHub Pages deployment and verify its HTTPS URL before updating the repository homepage.
- Install with the skills CLI, or use the shell installer to copy the skill's resources without checkout metadata and local dotfiles.

See the [quickstart and supported modes](https://github.com/ifthenelse/oss-showcase#installation) and the [project site](https://ifthenelse.github.io/oss-showcase/).
