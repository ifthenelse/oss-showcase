OSS Showcase

An Agent Skill for turning repository evidence into a README and a static project site, with a workflow for demos and launch drafts.

Install and invoke

From a project directory, run the installation command and choose your agent. Start in a disposable repository and review the generated files before publishing.

npx skills add ifthenelse/oss-showcase --skill oss-showcase

Start with a review

In Codex, use $oss-showcase audit. In Claude Code, use /oss-showcase audit. Use init when you are ready to generate a showcase for the target project.

Validate the public files

The Python generator creates a static site. The bundled validator checks the output and stages the public files for GitHub Pages. Review the content and media before deployment.
