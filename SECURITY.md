# Security policy

Security fixes are issued for the latest GitHub release. Before the first release, fixes land on `main`.

Report vulnerabilities using the [private vulnerability form](https://github.com/ifthenelse/oss-showcase/security/advisories/new). Include the affected ref, impact and minimal reproduction with synthetic data. Keep report details and credentials out of public issues and pull requests.

Maintainers coordinate disclosure with reporters after a fix is available. See [trust boundaries and mitigations](docs/security/threat-model.md).
